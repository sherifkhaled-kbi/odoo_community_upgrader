`NOT VERIFIED` Exact Python versions inside `odoo:17.0`, `:18.0`, `:19.0`; image digests; PostgreSQL version requirements of each image/upgrade; OpenUpgrade migration coverage for the installed modules; Enterprise addons source/license; localization/accounting/inventory readiness; customer custom module migration scripts.

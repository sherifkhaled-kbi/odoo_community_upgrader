## Other observations

`CONFIRMED` URL validation logs the full source string ([core.py:83](../../src/odooupgrader/core.py#L83)); signed URLs may therefore leak in logs. Downloads have no checksum/size cap ([core.py:144-169](../../src/odooupgrader/core.py#L144-L169)). `get_current_version` uses three fallbacks with `check=False` ([core.py:409-427](../../src/odooupgrader/core.py#L409-L427)); the final fallback may return a version for a base module that is not installed. The database name, service name, target image repository, and default PostgreSQL tag are hardcoded. Fixed SQL statements are constants, so no direct SQL injection was identified in this path. `NOT VERIFIED` Docker, network, actual SQL restore, Odoo integration, CI status, and security exploitability were not tested.
